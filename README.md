# پایان‌نامهٔ پروژهٔ کارشناسی

این مخزن حاوی پایان‌نامهٔ من برای پروژهٔ کارشناسی است.

## محتویات مخزن

- `template/`: نسخهٔ مرجع قالب LaTeX پروژهٔ کارشناسی است. این پوشه در مخزن نگه‌داری می‌شود تا ابزارهای هوش مصنوعی بتوانند با ساختار قالب، راهنمای نگارش و شیوهٔ درست استفاده از آن آشنا شوند. محتوای این پوشه ثابت است و تغییر نمی‌کند.
- `thesis/`: آخرین وضعیت پایان‌نامه و سورس LaTeX آن در این پوشه قرار دارد.
- `thesis.pdf`: آخرین خروجی PDF ساخته‌شده از پایان‌نامه است.

قالب مورد استفاده از مخزن [sinamomken/tehran-thesis](https://github.com/sinamomken/tehran-thesis) گرفته شده است.
