\enabstract{
Model checking automatically verifies desired properties by exploring a system's state space. In concurrent real-time models, combinations of component schedules, message queues, and timing constraints can cause rapid state-space growth and increase the cost of analysis. Model reduction offers a way to control this problem when it preserves the behavior under investigation.

This project investigates and implements the reduction of timed Rebeca semantic models using weak timed bisimulation. The method hides interactions outside the selected observation level and groups states that cannot be distinguished by observable behavior and elapsed time. A smaller model is then constructed from the resulting classes. Evaluation on the available examples indicates that the method can reduce model size while preserving the selected behavioral criterion. The project provides a basis for incorporating this form of reduction into the analysis of Rebeca models in Afra.
}
