\enabstract{
Model checking automatically verifies desired properties by exploring a system's state space. In concurrent real-time models, the combination of component schedules, message queues and timing constraints leads to state-space explosion, and what that explosion produces is a very large timed transition system. This thesis does not attempt to prevent that explosion while the state space is being generated. Its problem is to make the resulting system smaller \emph{after} it has been generated, so that it becomes practical to analyse, to inspect, and to compare against another model.

To that end, a tool was built that reads Afra's timed state-space export, hides the interactions the user did not declare observable, and groups the states that cannot be distinguished by observable behaviour and elapsed time. It then builds a smaller quotient model from those classes and checks its relation to the input with an independent verifier. The equivalence criterion is weak timed bisimilarity, and the structure of the algorithm is adapted from the partition refinement proposed for computing branching bisimulation on labelled transition systems.

The Rebeca and Afra toolchain generates and displays timed state spaces, but no tool was previously available to its users that reduced such a state space with respect to a chosen set of observable interactions; providing one is the main contribution of this work. Evaluation on the available examples and on state spaces generated from real Rebeca models shows that the method reduces model size while preserving the selected behavioural criterion, and that different models with the same observable behaviour are carried to the same reduced model.
}
